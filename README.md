# API Rede Campo Online

**English** | [Português](README.pt-BR.md)

Backend API for **Rede Campo Online**, a responsive website for the Rede Campo research group. A RESTful service built with Node.js and TypeScript, using Express and TypeORM for persistence on MariaDB/MySQL.

## Key Features

- **Modular Architecture**: Domain-Driven Design (DDD) and Clean Architecture
- **RESTful API**: Endpoints organized by domain
- **TypeScript**: Strict typing (`strict`) for easier maintenance
- **MariaDB/MySQL**: Relational persistence with schema versioned through migrations
- **JWT Authentication**: Access tokens with blacklist on logout
- **TSyringe**: Dependency injection
- **Celebrate/Joi**: Declarative request validation on routes
- **Cloudflare R2**: Image storage, with WebP variants generated by Sharp
- **Helmet, CORS, and rate limiting**: HTTP security layer

## Quick Start

1. **Clone the repository:**

   ```bash
   git clone https://github.com/diegodallaqua/API-rede-campo-online.git
   ```

   ```bash
   cd API-rede-campo-online
   ```

2. **Install dependencies:**

   ```bash
   npm install
   ```

3. **Configure the environment:**

   ```bash
   cp .env.example .env
   # Edit .env to match your environment
   ```

4. **Database:**

   ```sql
   CREATE DATABASE db_rede_campo_online;
   ```

   ```bash
   npm run migration:run
   ```

5. **Run in development:**

   ```bash
   npm run dev
   ```

6. **Check:** `GET /health` should return `{ "ok": true }`.

For details, see [Installation](md/instalacao.md) and [Configuration](md/configuracao.md).

## Available Resources

The API exposes a health check at `GET /health` and the following resources:

- `/sessions` - authentication (login and logout)
- `/states`, `/cities`, `/addresses` - location
- `/organizations`, `/member-roles`, `/members` - members and organizations
- `/project-types`, `/projects`, `/project-media` - projects
- `/events`, `/event-media` - events
- `/news`, `/news-media` - news
- `/research-areas` - research areas
- `/publications`, `/external-authors`, `/contributor-role`, `/publication-contributors` - publications and contributors
- `/articles`, `/academic-works`, `/books`, `/book-chapters` - publication types
- `/academic-work-types` - academic work types (read-only)
- `/images` - image upload (Cloudflare R2)

As a rule, reads are public and writes require JWT authentication (`Authorization: Bearer <token>`). Exceptions and parameters for each endpoint are listed in the [API Reference](md/documentacao-da-api.md).
